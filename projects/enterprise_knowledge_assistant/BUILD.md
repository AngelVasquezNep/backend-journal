# Spec-kit

```sh
$speckit-constitution Taskify is an application that responds user's questions. All user inputs must be validated. We use a microservices architecture. Code must be fully documented.
```

```sh
$speckit-specify Develop Taskify, a team productivity platform where predefined users create projects, assign tasks, comment, and move tasks across Kanban columns (To Do, In Progress, In Review, Done). Five users (one product manager, four engineers), three sample projects, no login for this first phase.

$speckit-specify Develop Taskify, a Q&A platform where different owners/companies load information (documents, images, etc.) and users can query about it. Owners (company admins) can edit this info. Clients (By compnay) can read it. There are two roles (admin, users), Admins are created by CLI command and admins can create users. Login system is required.
```
